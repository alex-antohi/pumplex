# Animations for all 50 bodies

Generated by `node tools/moodboard/animate_all.mjs` from `docs/moodboard/creator/body_atlas.png`.
Output: `atlas/idle_atlas.png`, `atlas/front_squat_atlas.png`, `atlas/level_up_flex_atlas.png`, `atlas/animation_atlas.json`.

## Layout
- Cell is 80x72, not 52x64: the 52x64 body sits at offset (14, 8) so the bar, plates and flexed arms fit. Same col/row rule as body_atlas: col = fat/25, row = (female ? 5 : 0) + muscle/25.
- One atlas per animation. Pose blocks (5 cols x 10 rows = 400x720) sit side by side in `sheetOrder`; pose i, col c: x = (i*5 + c)*80, y = row*72.
- Frame order and `ms` per animation are in `animation_atlas.json` (`frames`). Draw at whole-number nearest-neighbour scale.
- Sizes: idle 800x720 (2 poses), front_squat 2000x720 (5), level_up_flex 2400x720 (6).

## Rename
`pr_flex` is now `level_up_flex` (level-up / critical set; no PRs, D2). Poses and timing are unchanged. The old 6-body folders (`<body>_/pr_flex_*.png`, `animation.json`) are untouched and still say `pr_flex`.

## Checks
- 50 bodies x 3 animations = 150 body-animations; 13 distinct poses per body (2 + 5 + 6), 650 frames.
- The 6 bodies of the old style test are pixel-identical to the old frames (78 frames compared, 0 mismatches).
- Every cell is non-empty; automatic checks (pixel count vs rest, pose differs from rest, no touching the frame edge) flagged no body. These are heuristics, not a visual review.

## Fallback rule
No body was flagged, so no fallback is used today. If review finds a body whose arms or legs are cut wrongly, replace its frames with the nearest clean body, same sex, in this order: same fat, muscle +/-25; then same muscle, fat +/-25; then the nearest on the diagonal. Prefer the lower-muscle neighbour on ties. Set `ok: false` on that body in `animation_atlas.json`.
