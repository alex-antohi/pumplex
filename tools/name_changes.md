# Name changes (D90 step 4)

Every exercise name that changes on screen, old → new, in English and Romanian. Check them.
A name in bold is new; a name without bold did not change in that language.

- Hand names (`exercise.<id>` in en.json and ro.json): 209 → 55. In the app list: 190 → 36; the other 19 are ids that left the list (old saved sets).
- Exercises with a new name: 148 (en 104, ro 112). No id changed; saved sets, favorites and Today keep their ids.
- A hand name stays for a gym name (Butterfly, Military Press, Glute-Ham Raise, Trap Bar Deadlift, T-Bar Row), and where the composed name is too long or wrong (for example the overhead triceps extensions, the plate-loaded machines, the leg press stances).
- New rules (move words per value): the cardio machines, Ab Wheel Rollout, Hanging Knee Raise, Hanging Pike, Reverse Wrist Curl, Stiff-Legged Deadlift, Decline Sit-Up, Feet-Elevated (inverted row), Sprijin la inele. Seated is left out of Wrist Curl names (every wrist curl there is seated).
